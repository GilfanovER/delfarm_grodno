## Описание проекта
Данный курсовой проект представляет собой полноценное Fullstack веб-приложение (маркетплейс), разработанное для автоматизации процессов заказа и доставки свежей продукции от местных фермерских хозяйств жителям г. Гродно. Проект решает проблему сбыта для малого агробизнеса и предоставляет горожанам удобный инструмент для покупки экологически чистых продуктов питания. В систему встроен аналитический модуль (СППР) для поддержки принятия решений фермерами.

## Технологический стек
- **Backend:** Node.js, Express, Sequelize (ORM).
- **Database:** PostgreSQL.
- **Frontend:** React (Vite), Tailwind CSS v4, Recharts.
- **Безопасность:** JWT (JSON Web Tokens), Bcryptjs (хеширование паролей).
- **Интерфейс и иконки:** Lucide React, Responsive Design (Mobile-First).

## Функциональные модули
- **Модуль Клиента:** каталог продукции, умная фильтрация и поиск, корзина с динамическим расчетом доставки, оформление заказа с выбором времени, история заказов, система отзывов и рейтингов.
- **Модуль Фермера:** дашборд с оперативной аналитикой (KPI), управление товарными позициями (CRUD, мгновенное редактирование остатков), обработка поступающих заказов (подтверждение/отклонение).
- **Модуль Администратора:** верификация и одобрение новых фермерских хозяйств, модерация пользовательских отзывов.
- **Аналитический модуль (СППР):** графики динамики продаж с расчетом отклонений, ABC-анализ номенклатуры (по правилу Парето), география спроса по микрорайонам Гродно и оперативные алерты остатков.

## Инструкция по запуск проекта

### 1. Настройка базы данных
1. Установите СУБД PostgreSQL и создайте пустую базу данных (например, `farmfood_db`).
2. В корне проекта создайте файл `.env` на основе шаблона и укажите свои доступы:
   ```env
   PORT=5000
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_от_ postgres
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=farmfood_db
   JWT_SECRET=super_secret_farmfood_key_2026

### 2. Инициализация и наполнение базы данных
Откройте терминал в корне проекта и выполните по порядку следующие команды:

#### Установка зависимостей бэкенда
```bash
npm install
```
#### Создание таблиц и структуры в PostgreSQL
```bash
node setup-db.js
```
#### Заполнение базы базовыми учетными записями и каталогом
```bash
node seed.js
```
#### Наполнение базы данных реалистичными тестовыми данными (заказы за 30 дней, клиенты и товары по районам г. Гродно)
```bash
node seed_analytics_realistic.js
```

### 3. Запуск Бэкенда (Серверная часть)
В корневом терминале выполните:
```bash
npm start
```
(Сервер запустится на порту 5000).

### 4. Запуск Фронтенда (Клиентская часть)
Откройте второй терминал в папке проекта, перейдите в директорию клиента и запустите приложение:
```bash
cd client
npm install
npm run dev
```
(Сайт откроется в браузере по адресу http://localhost:5173).
